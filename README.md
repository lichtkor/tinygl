# tinygl
quick opengl and glfw wrapper that is cross-platform friendly

## How I imagine it
My idea of **TinyGL** is a abstraction of OpenGL 3.3 and GLFW it should ease the process of
creating a window, adding text or other components to it. For now if using TinyGL include the
`tinygl.h` header file in your source file and compile the tinygl.cpp.
